## Overview

Python Foundations presents a focused set of small Python programs that demonstrate
core language concepts through readable, executable examples. Each script is
designed to make one idea easy to understand, from string handling and formatting
to dynamic typing and duck typing.

The repository is part of my programming portfolio and reflects a practical,
incremental approach to writing clean and understandable Python code.

## What is included

| Script | Focus |
| --- | --- |
| [`hello_world.py`](hello_world.py) | A minimal Python program |
| [`input_output_basics.py`](input_output_basics.py) | Console input and formatted output |
| [`string_checks.py`](string_checks.py) | String validation and character checks |
| [`text_formatting.py`](text_formatting.py) | Splitting, joining, aligning, and replacing text |
| [`data_transformation.py`](data_transformation.py) | Number, character, and string transformations |
| [`dynamic_typing_demo.py`](dynamic_typing_demo.py) | Runtime variable types in Python |
| [`duck_typing_demo.py`](duck_typing_demo.py) | Behavior-oriented type compatibility |

## Getting started

### Requirements

- Python 3.8 or later
- A terminal and a code editor such as [Visual Studio Code](https://code.visualstudio.com/)

### Run the examples

Clone the repository and open the project directory:

```bash
git clone https://github.com/PVegananda/python-foundations.git
cd python-foundations
```

Run any example with Python:

```bash
python3 hello_world.py
```

On Windows, use `python` if `python3` is not available:

```bash
python hello_world.py
```

No third-party packages are required.

## Project structure

The examples are intentionally kept as independent scripts, so each concept can
be read and run without additional setup. This keeps the code approachable while
making the repository easy to extend with focused Python demonstrations.
