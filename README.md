<h2>📌 Project Overview</h2>
<p>
The <strong>BelajarPython</strong> repository is a personal learning collection containing various Python scripts, 
exercises, experiments, and introductory programs.  
This project is designed for beginners who want to understand Python fundamentals through simple, clear, and practical examples.
</p>

<h2>🎯 Learning Goals</h2>
<ul>
  <li>Understand Python syntax and basic structures</li>
  <li>Practice variables, loops, conditions, and functions</li>
  <li>Learn to build small interactive programs</li>
  <li>Explore beginner-friendly problem-solving tasks</li>
</ul>

<br/>

<h2>📁 Repository Contents</h2>

<h2>🛠 2. Running Python Scripts</h2>

<h3>🍎 macOS (MacBook)</h3>
<ol>
  <li>Check Python installation:</li>
</ol>
<pre>python3 --version</pre>

<ol start="2">
  <li>Run any script:</li>
</ol>
<pre>python3 scriptname.py</pre>

<br/>

<h3>🪟 Windows</h3>
<ol>
  <li>Install Python from <a href="https://www.python.org/downloads/">python.org</a></li>
  <li>Run script using:</li>
</ol>
<pre>python scriptname.py</pre>
